# Piazza Discussion Platform

A discussion platform where users can register to participate in discussions. Registered users can create posts under topics, comment on posts, and react to posts.

## Tech Stack

- **Python and FastAPI** – Backend development.
- **Pydantic** – Data validation and request/response schemas.
- **SQLAlchemy and SQLite** – ORM and relational data storage.
- **JWT Bearer Authentication** – User authentication and access control.
- **pytest and FastAPI TestClient** – Automated testing.
- **Docker and Docker Hub** – Containerisation and image distribution.
- **Google Cloud and Kubernetes** – Cloud deployment and container orchestration.
